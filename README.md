# Aivoa AI CRM

## Features
- FastAPI Backend
- React + Vite Frontend
- AI Chat API
- Groq LLM Integration

## Tech Stack
- Python
- FastAPI
- React
- Vite
- Groq API

## Installation

### Backend

pip install -r requirements.txt

uvicorn app.main:app --reload

### Frontend

npm install

npm run dev
